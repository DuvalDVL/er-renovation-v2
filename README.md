# Site ER Rénovation (Jekyll, GitHub Pages)

Site prêt pour la production : `er-renovation.com`, indexable, formulaire et mesure d'audience configurés.

## Mise en ligne
1. Dépôt GitHub : y envoyer tout ce dossier (y compris `.github` et `CNAME`).
2. Réglages > Pages > Source : « GitHub Actions ».
3. Si l'ancien dépôt porte déjà le domaine : le retirer de ses réglages Pages (Custom domain), puis le saisir dans le nouveau dépôt et cocher « Enforce HTTPS ».
4. Photos : déposer les originaux dans `assets/img/originals/`, nommés comme les emplacements du site (voir `A_MODIFIER.md`). Le workflow les optimise.
